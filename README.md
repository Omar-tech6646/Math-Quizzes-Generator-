 Math Quiz Generator

A simple console-based application that generates random math quizzes to help users practice and improve their mathematical skills.

Overview

The Math Quiz Generator is a console application that creates interactive math quizzes with randomly generated questions. Users can answer different mathematical problems, receive immediate feedback, and check their final results at the end of the quiz.

The project is designed to practice programming fundamentals, logical thinking, and problem-solving skills.

 Features

* Random Questions: Generates random mathematical questions.
* Multiple Operations: Supports basic arithmetic operations:
    * Addition (+)
    * Subtraction (-)
    * Multiplication (×)
    * Division (÷)
* Interactive Quiz: Allows users to enter answers directly through the console.
* Instant Feedback: Checks answers and informs users whether they are correct or incorrect.
* Final Results: Displays the user’s score and performance after completing the quiz.
